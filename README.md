# Étude col fémoral – formulaire

Page du formulaire de saisie de l'étude prospective sur les fractures du col fémoral traitées par arthroplastie (Service de Chirurgie Orthopédique et Traumatologique, EHS Benaknoun).

Ce dépôt ne contient que la page : aucune donnée de patient. Les fiches sont enregistrées dans un Google Sheets privé, accessible au seul responsable de l'étude. L'accès au formulaire se fait avec un code personnel.
